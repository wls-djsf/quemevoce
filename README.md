## 📌 Sobre o Projeto

Este projeto consiste em uma interface de login moderna, elegante e responsiva, desenvolvida com **HTML5** e **CSS3** puro. O design adota o conceito de **Glassmorphism** (efeito de vidro translúcido com desfoque de fundo e contornos iluminados em neon), sobreposta a uma arte temática de alto impacto inspirada no Homem-Aranha.

A interface foi estruturada com foco em estética minimalista, boa legibilidade e experiência de usuário imersiva.

## ✨ Funcionalidades e Destaques Visuais

- 🔮 **Efeito Glassmorphism**: Caixa de login com transparência suave, desfoque de fundo (`backdrop-filter: blur`) e bordas com brilho suave (*glow*).
- 👤 **Campos de Entrada Personalizados**:
  - Campo de **Usuário** com ícone representativo (`bxs-user`).
  - Campo de **Senha** seguro com ícone de cadeado (`bxs-lock-alt`).
- 🔘 **Ações do Usuário**:
  - Opção de seleção **"Lembrar Senha"**.
  - Link para recuperação de acesso (**"Esqueci a Senha"**).
  - Atalho para criação de nova conta (**"Cadastre-se"**).
- 🎨 **Interatividade e Transições**: Animações de foco e *hover* no botão de login e links interativos.
- 📱 **Design Responsivo**: Adaptado para uma boa visualização em telas de computadores e dispositivos móveis.

## 💻 Como Executar Localmente

Para clonar e testar o projeto no seu computador:

1. Clone o repositório via terminal:
   ```bash
   git clone https://github.com/wls-djsf/login.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd login
   ```

3. Abra o arquivo `index.html` em qualquer navegador web moderno:
   - Dê um clique duplo em `index.html`, ou
   - Utilize a extensão **Live Server** no VS Code.
